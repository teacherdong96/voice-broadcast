# 定时语音播报软件（教室希沃大屏版）

Windows 桌面小工具：到点自动语音播报文字，同时在屏幕中央弹出半屏大横幅，点击任意处或大红关闭按钮即关闭。专为教室希沃触控大屏优化。

## 本次针对希沃大屏做了什么

- **横幅真正占一半屏幕**：宽=屏幕宽度 50%，高=屏幕高度 50%，居中显示，不挡整块黑板视角。
- **大字体大按钮**：正文 48pt 加粗，关闭按钮 160×80 红色圆角，教室后排也看得清、触控点得准。
- **点击任意处即关**：希沃触控笔/手指点一下横幅任意位置就能关，不一定要精确点 ×。
- **蓝色描边白底**：投影/强光下对比足够，不反光看不清。

## 你需要做的（重要）

我这边运行在 Linux 服务器上，**PyInstaller 不能跨平台编译 Windows exe**，所以没法直接把 `.exe` 发给你。请按下面三步在一台普通 Windows 电脑上打一次包，产出的 exe 再拷到希沃上即可：

### 第一次打包（约 5 分钟，只需做一次）

1. 找一台 Windows 10/11 电脑，先装好 [Python 3.8+](https://www.python.org/downloads/)，**安装时务必勾选 "Add Python to PATH"**。
2. 解压本压缩包。
3. **双击 `build.bat`**。脚本会自动：
   - 建虚拟环境
   - 用清华镜像装依赖（快）
   - 调 PyInstaller 打包成单文件 exe
4. 完成后打开 `dist\` 文件夹，里面就是 **`定时语音播报.exe`**。

### 部署到希沃

1. 把 `定时语音播报.exe` 拷到 U 盘。
2. 插到希沃上，复制到桌面或 D 盘。
3. 双击运行。如果弹 Windows SmartScreen 蓝色提示，点「更多信息」→「仍要运行」。
4. 软件最小化到托盘后台运行，到点自动弹窗+语音。

> 希沃电脑不需要装 Python、不需要装任何运行库，exe 是单文件绿色版。

## 软件功能

| 区域 | 功能 |
|---|---|
| 顶部全局设置 | 开机自启勾选、音量、语速、横幅停留秒数、「最小化到托盘」按钮 |
| 任务设置区 | 播报内容输入 + HH:mm 时间 + 周一~周日勾选 + 添加/保存按钮 |
| 已有任务区 | 每行带复选框（勾选=启用）；单击文字编辑；右键编辑/删除 |
| 横幅 | 半屏居中、大字体、大红色关闭按钮、点任意处关闭 |
| 托盘 | 双击图标还原主界面，右键菜单可真正退出 |

## 教室场景常见问题

- **没声音**：希沃一般自带中文语音包。如无声，进 Windows「设置 → 时间和语言 → 语音」确认有「Microsoft Huihui / Yaoyao / Kangkang」等中文语音。
- **开机自启没生效**：希沃教学镜像可能禁用了注册表 Run 项。改用 Windows「任务计划程序」，触发器选「登录时」，操作选启动这个 exe 即可。
- **横幅太挡事**：把「横幅停留秒数」设成比如 30，30 秒后自动关；或直接点一下关掉。
- **想换音色**：用了系统默认语音。如需指定音色，在 `speech.py` 里 `engine.setProperty('voice', 语音ID)` 改一行即可。
- **希沃是触摸屏**：所有按钮尺寸都按触控放大，用手指或触控笔直接点就行。
